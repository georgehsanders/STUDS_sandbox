{% if current_step == 0 %}

Click the Start Side-by-Side Mode button at the top of this page to open the Zebra portal alongside the tutorial. Then log in with your store credentials.

{% elif current_step == 1 %}
  1. 1.a) Click on “My Data” on the left.
  2. 1.b) Click on the three dots for the old Zebra files you want to delete and select “Remove”.
  3. 1.c) Click “Remove linked file”.
  4. 1.d) Repeat for all old files until your data files are empty.
{% elif current_step == 2 %}
  1. 2.a) Download the new data files to your computer.
    DOWNLOAD NEW DATA FILES
    Click to download the latest master files from HQ as a ZIP. Extract the ZIP to get all 5 files, then drag each one into Zebra in Step 2.b.
  2. 2.b) Click “Upload File” in Zebra and double-click on the first (of 5) files to drop it into Zebra.
  3. 2.c) Repeat this process until all five of the new Zebra files are in your portal.
{% elif current_step == 3 %}
  1. 3.a) Click on “My Designs” on the left.
  2. 3.b) Click on your first label template (1 Bin Labels - Fashion) and click “Edit”.
  3. 3.c) Click the Lock icon in the top right corner to unlock the design.
  4. 3.d) Click on the (-) button to disconnect the old data file and click “Disconnect”.
  5. 3.e) Click “Connect Data File” in the top right corner and select the correct corresponding data file that matches the title of the template you are in.
{% elif current_step == 4 %}

For bin labels, there are four fields you have to map: Description, SKU Barcode, Material, and SKU.

  1. 4.a) Click on your first field — the “Description” text box — and switch the input from Manual to From Data File.
  2. 4.b) Change the “Column from Data File” from SKU to DESCRIPTION.
  3. 4.c) You’ve successfully mapped your first data field. Now repeat these steps for the remaining three fields:
    • SKU Barcode: switch Input to “From Data File”, Column from Data File should be SKU
    • Material: switch Input to “From Data File”, Column from Data File should be MATERIALS
    • SKU (text): switch Input to “From Data File”, Column from Data File should be SKU (same as the barcode, but this field renders the SKU as text)
{% elif current_step == 5 %}

When complete, your newly mapped bin label template should look like the example below. Hit the Lock button in the top right corner again to lock in your changes, then test-print a label to confirm everything is mapped correctly.

Once locked, click “Exit Designer” and repeat Steps 3 through 5 for the remaining four templates.
